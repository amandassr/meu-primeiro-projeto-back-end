# Primeiro projeto back-end com Node.js

Projeto desenvolvido durante o curso Eu Programo para praticar os fundamentos de uma aplicação back-end com **Node.js** e **Express**.

## Objetivo

Compreender a estrutura inicial de um servidor, a criação de rotas e a organização de dados em uma API simples.

## Tecnologias utilizadas

- JavaScript
- Node.js
- Express

## Aprendizados

- Configuração de um servidor local
- Criação e teste de rotas
- Organização de arquivos JavaScript
- Uso de dependências com npm

Este é um projeto de formação e registra uma das minhas primeiras experiências práticas com desenvolvimento back-end.
